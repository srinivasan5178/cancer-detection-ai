## 4. Reporting protocol

- Report the held-out test metrics once, after model selection is complete.
- Include class-wise precision, recall, F1-score, support, and a confusion matrix.
- Include the validation objective used by GWO (for example, validation Macro-F1) and the selected CatBoost parameters.
- State the number of runs/folds and report mean ± standard deviation only when repeated runs or folds support that statistic.
- Record random seeds, package versions, split counts, and timing environment.
- Explain any class imbalance, data exclusions, augmentation, or limitations.
- Do not claim clinical or diagnostic readiness from image-classification metrics alone.
